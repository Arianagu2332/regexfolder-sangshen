# 正则分组管理器

这是一个面向 SillyTavern 1.19 系列的第三方 UI 扩展原型。它在原生正则面板中增加管理层，不改写正则内容本身。

## 已实现的第一版

- “全局正则脚本 / 预设正则脚本 / 局部正则脚本”三类默认折叠，点击“展开”后显示。
- 每个分类可以创建多个文件夹。
- 每条正则行增加文件夹选择框，可在“未分组”和自定义文件夹之间移动。
- 文件夹支持折叠、改名、删除。
- 文件夹支持一键打开或关闭其中的正则。
- 每个分类额外提供“全开/全关”。
- 分组、文件夹名称、文件夹折叠状态和三类分类折叠状态保存在 SillyTavern 的 `extensionSettings` 中，并通过 `saveSettingsDebounced()` 持久化。
- 扩展卸载清理时会把正则行移回宿主容器，避免删除原生正则节点。

## 安装

将整个 `正则分组管理器` 文件夹放入 SillyTavern 的第三方扩展目录，然后在扩展管理器中启用。当前版本没有自动安装到任何实例，也不会修改你的正则文件。

## 存储边界

这是浏览器端 UI 扩展，不能直接把 JSON 写进扩展文件夹。第一版使用 SillyTavern 的服务端扩展设置存储，因此数据不放在 `localStorage` 中，也不会因为换浏览器而天然丢失；它仍然跟随当前 SillyTavern 用户实例的设置数据。若 Tauritavern 提供稳定的后端文件接口，后续可以再增加导入/导出或独立文件存储。

## 当前需要在 Tauritavern 中验收的内容

正则面板的实际 DOM 属于宿主实现细节，静态检查无法证明以下行为：

1. 三个分类标题是否被运行时识别。
2. 正则行的启用按钮是否能被准确识别和点击。
3. 创建、编辑、删除正则后，分组和折叠是否仍然保持。
4. 切换聊天、切换预设、刷新页面后，分组设置是否正确恢复。
5. Tauritavern 是否完整实现了 SillyTavern 1.19 的 `extensionSettings` 和 `saveSettingsDebounced`。

如果 Tauritavern 的正则面板选择器与 SillyTavern 不同，需要你提供 Tauritavern 仓库或一次浏览器运行时结构信息，我再补适配层。

### 备用标识说明

如果宿主没有给正则行提供稳定的 `data-*` 标识，第一版会用正则名称生成备用标识；同名正则或改名后可能需要重新选择文件夹。
